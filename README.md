# 跨境物流大挑戰（amazon-logistics-game）

依 Amazon 跨境電商「物流費用」教材（賣家→出口報關→空運/海運→進口清關關稅→貨運→FBA倉/FBM→買家的完整流程，與國際商業快遞／海運／空運三種運輸方式定義）改編的兩關互動教學小遊戲。

- **第一關・物流流程拼圖**：拖曳 9 張流程卡到流程圖對應位置，重現分岔匯流的完整物流路徑。
- **第二關・運輸方式情境選擇**：6 組出貨情境，三選一判斷該用快遞／海運／空運，並附完整定義文字回饋。

單檔前端（`index.html`），無建置步驟、無框架、零外部資源。直接開啟 `index.html`（`file://`）或以靜態伺服器託管即可。詳見 `CLAUDE.md`。
